כלי יצירה ובדיקה של קובץ מבצעים
=================================

דרישות:
- Windows
- Microsoft Excel מותקן

איך עובדים:
1. חלצו את כל קובצי ה-ZIP לאותה תיקייה.
2. לחצו פעמיים על 01_create_promotion_excel.bat.
3. ייווצר קובץ בשם מבצעים_תאריך_שעה.xlsx.
4. מלאו שורה אחת לכל מבצע.
5. בכל שורה בחרו סוג מבצע. התאים הצהובים הם שדות חובה לסוג שנבחר.
6. את המוצר יש לבחור מהרשימה בלבד. אין להקליד מוצר שלא נמצא ברשימה.
7. אפשר להגדיר כמה מבצעים שונים על אותו מוצר.
8. לאחר סיום, סגרו את קובץ האקסל ולחצו פעמיים על 02_validate_promotion_excel.bat.
9. אם נמצאו שגיאות, פתחו את האקסל ובדקו את העמודות סטטוס ושגיאות.
10. כאשר הבדיקה עוברת, ייווצר גם הקובץ מבצעים_מאומתים.json.

סוגי המבצעים והשדות שלהם:
- אחוז הנחה: מוצר, אחוז הנחה.
- מחיר קבוע: מוצר, מחיר קבוע.
- כמות בסכום: מוצר, כמות במבצע, מחיר כולל במבצע.
- הנחה בשקלים: מוצר, סכום הנחה.
- מבצע משלוח לפי סכום סל: סכום סל מינימלי, דמי משלוח במבצע. עבור משלוח חינם יש להזין 0.
- מתנה לפי סכום סל: מוצר המתנה, סכום סל מינימלי, כמות מתנה.
- מחיר מיוחד למוצר לפי סכום סל: מוצר ההטבה, סכום סל מינימלי, מחיר מיוחד למוצר.

מקסימום מימושים להזמנה:
- שדה אופציונלי במבצעי מוצר.
- בכמות בסכום, לדוגמה 2 ב-9.90 עם מקסימום 3, ניתן לממש את המבצע עד 3 פעמים, כלומר עד 6 יחידות.
- במחיר מיוחד למוצר לפי סכום סל, השדה מגביל את כמות מוצרי ההטבה.
- במבצע משלוח ובמתנה לפי סכום סל יש להשאיר את השדה ריק.
